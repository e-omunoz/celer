# Code of conduct

Celer is built by people who care about good tools. We want this project to be a friendly place for everyone,
whatever their experience, background or identity.

**Expected:** be kind and patient, assume good intent, give feedback on the work and not the person, and help newcomers.

**Not accepted:** harassment, insults, discriminatory jokes or language, personal attacks, publishing other people's
private information, and any behaviour that would be inappropriate in a professional setting.

This applies to issues, pull requests, discussions and any other project space.

If something makes you uncomfortable, contact the maintainers privately through
[GitHub Security Advisories](https://github.com/e-omunoz/celer/security/advisories/new) or by email to the repository
owner. Reports are handled confidentially. Maintainers may edit or remove content, and may temporarily or permanently
ban contributors who do not follow this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
